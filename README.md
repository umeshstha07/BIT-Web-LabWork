# Web Technology Lab Practicals

## Introduction

This repository contains the lab practical work I have completed while studying at BMC (Bhaktapur Multiple Campus), Nepal. The practicals are related to the basic concepts of web technology, including HTML, CSS, JavaScript, and XML.

The main purpose of this work is to practise the topics learned in class and understand how these technologies are used to create and organise web content.

## Topics Covered

### 1. HTML (HyperText Markup Language)

HTML is used to create the structure of web pages. Through the HTML practicals, I practise:

- Creating the basic structure of an HTML document.
- Using headings, paragraphs, links, and images.
- Creating ordered and unordered lists.
- Working with tables.
- Creating forms and different input fields.
- Using semantic HTML elements to organise page content.

### 2. CSS (Cascading Style Sheets)

CSS is used to control the appearance and layout of web pages. The CSS practicals cover:

- Applying inline, internal, and external CSS.
- Changing colours, fonts, and text styles.
- Working with margins, padding, and borders.
- Styling links, lists, tables, and forms.
- Using the CSS box model.
- Arranging content with basic layout techniques.
- Making web pages responsive using media queries.

### 3. JavaScript (JS)

JavaScript is used to add interaction and dynamic behaviour to web pages. The JavaScript practicals cover:

- Writing and using JavaScript variables.
- Working with operators and expressions.
- Using conditional statements and loops.
- Creating and calling functions.
- Working with arrays and objects.
- Handling events such as button clicks.
- Accessing and changing HTML elements using the DOM.
- Performing basic form validation.

### 4. XML (Extensible Markup Language)

XML is used to store and organise data in a structured, readable format. The XML practicals cover:

- Understanding the basic structure of an XML document.
- Creating elements and attributes.
- Working with parent and child elements.
- Creating well-formed XML documents.
- Understanding the purpose of XML namespaces.
- Using XML to represent structured information.

*The topics listed above describe the areas covered by this practical collection. The exact exercises may vary according to the files included in the repository.*

## How to Run and View the Practicals

Most HTML, CSS, and JavaScript practicals can be viewed in a web browser.

1. Download or clone this repository to your computer.
2. Open the project folder in a code editor such as Visual Studio Code.
3. Find the HTML file for the practical you want to view.
4. Open the HTML file in a web browser.
5. If the practical uses separate CSS or JavaScript files, keep those files in their expected locations.
6. For XML practicals, open the `.xml` file in a code editor or a browser to view its structure.

Some practicals may need to be opened from their own folders. Keep the original folder structure and file names so that linked files work correctly.
